# Tienda deportiva

Tienda online de ejemplo hecha mientras aprendo programación en CEAC Valencia.

**Pruébala:** https://hevertonmf.github.io/tienda-deportiva/

- Más de 100 productos con buscador y filtros por categoría
- Carrito tipo ticket donde puedes añadir y quitar productos
- Panel de administración con los pedidos, los artículos vendidos y el total facturado

La versión original funciona con **Python + Flask + SQLite**: los productos salen de la base de datos y los pedidos se guardan con un `fetch` POST. Esta demo es la versión estática para GitHub Pages: los productos vienen de `productos.json` y los pedidos se guardan en el navegador (localStorage).
